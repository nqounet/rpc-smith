# rpc-smith

鍛える、組む、応える — JSON-RPC サーバー実装の道場

## キャッチフレーズ
鍛錬で極める JSON‑RPC サーバー実装。小さな課題を反復して、「使える」実装力を手に入れる。

## 概要
rpc-smith は JSON‑RPC のサーバー実装を反復練習するための教材／テンプレート集です。複数言語・複数フレームワークでの「同じ課題」を用意し、実装力と理解を段階的に高めます。

- 対象: JSON‑RPC を学びたいエンジニア（初級〜中級）
- 目的: 基本動作の理解、エラーハンドリング、同時接続、認証、テストの書き方を繰り返し身につける
- アプローチ: 小さな「ドリル（練習課題）」を短時間で繰り返す

## 主要なキャッチ内容（短い説明）
- シンプルな課題設計：少しずつ積み上げるステップ
- 言語別サンプル：Go / Rust / Node / Python などの参照実装
- テスト重視：ユニット＆統合テスト例を収録
- ハンズオン向け：手元で繰り返すためのチェックリストと自動化スクリプト

## ディレクトリ構成（推奨）
- /exercises/<id>-<slug> — 各ドリルの課題説明とテスト仕様
- /implementations/<lang>/<id>-<slug> — 言語別の実装例
- /tools — 自動テスト・スクリプト・ベンチマーク
- /docs — 補足資料・設計メモ

## はじめ方（例）
```bash
# リポジトリをクローン
git clone https://github.com/<your-org>/rpc-smith.git
cd rpc-smith

# まずは最初のドリルを実行（言語別ディレクトリで）
cd implementations/nodejs/0001-hello-rpc
npm install
npm test
```
