# 0010 - Full Roundtrip Demo (server + client)

目的: 小さな HTTP で動く JSON‑RPC サーバーと、クライアント（簡易）を用意してフルのリクエスト/レスポンス・バッチ・通知・エラーを扱うデモを作る。

やること:
- 簡易サーバーを起動する（`/rpc` エンドポイント）。
- クライアントを使って `hello`, `sum`, バッチ（通知含む）, `divide`（エラー） を実行する。

難易度: 入門

ヒント:
- 言語は自由（Node, Python, Go など）。教育用なので単一ファイルで完結させると良い。
- テストスクリプトで自動的にサーバー起動→リクエスト→出力確認まで行うと分かりやすい。

検証例（期待されるクライアント出力）:
- `Hello, world!` の結果
- `sum` の数値 など
- バッチの配列レスポンス（通知分は含まれない）

## テスト仕様

- フルワークフローの例（クライアントが順に実行）:
	1. `hello` (id=1) → 期待: `Hello, world!`
	2. `sum` (id=2) with params `[2,3]` → 期待: `5`
	3. バッチ（通知含む）→ 通知分はレスポンスに含まれないこと
	4. `divide` でエラーを発生させる → 期待: エラーオブジェクト

- サンプルリクエスト/期待レスポンスは各個別課題（0001〜0009）を参照すること。
